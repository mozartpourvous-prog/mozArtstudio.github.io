MOZART STUDIO — PORTFOLIO WEBSITE

Isi paket:
- index.html: website utama
- assets/: 14 gambar karya yang disediakan untuk galeri

Pratinjau lokal:
1. Ekstrak ZIP ke folder.
2. Buka index.html di browser.

Publikasi:
1. Unggah folder ini ke hosting statis seperti Netlify atau GitHub Pages. Pastikan index.html berada di root folder publikasi.
2. Beli domain yang tersedia melalui registrar.
3. Tambahkan domain di pengaturan hosting, lalu ikuti petunjuk DNS dari penyedia hosting.

Sebelum diluncurkan:
- Ganti email contoh hello@mozartstudio.com dengan alamat email aktif milik Anda.
- Periksa ketersediaan dan status kepemilikan mozartstudio.com dan mozartstudio.id melalui registrar resmi sebelum membeli.
- Pastikan Anda memiliki hak untuk menampilkan semua karya yang dipublikasikan.

Catatan: website ini berupa HTML/CSS/JavaScript statis; tidak memerlukan database atau proses build.
